# Telegram-бот для поиска внутренних документов сотрудников

## О проекте

Итоговый учебный проект в рамках программы повышения квалификации ТГУ «Специалист по информационным системам: оптимизация процессов создания цифровых решений».

Я разработала Telegram-бота для сотрудников строительной компании, чтобы упростить поиск типовых документов: шаблонов смет, актов КС-2 и заявлений на отпуск.

## Проблема

Раньше сотруднику приходилось обращаться в рабочий чат или звонить коллегам, чтобы получить нужный документ. Это занимало время и отвлекало других специалистов от работы.

## Моё решение

Я собрала Telegram-бота на no-code платформе Make.com и настроила маршрутизацию запросов через Router.

Бот распознаёт запросы по ключевым словам и отправляет ссылку на соответствующий документ. Для неизвестных запросов предусмотрена отдельная ветка Fallback.

## Что я сделала

- Описала существующий процесс поиска документов (AS-IS).
- Предложила оптимизированный процесс (TO-BE).
- Разработала сценарии взаимодействия сотрудника с ботом.
- Настроила ветвление запросов в Make.com.
- Проверила работу бота на нескольких типовых запросах.
- Исправила проблему распознавания слов с разным регистром.
- Выявила возможные риски эксплуатации и предложила меры по их снижению.

## Результат

Создан и протестирован учебный прототип Telegram-бота, который помогает сотрудникам получать ссылки на типовые документы без обращения к коллегам.

Проект является учебным прототипом и не внедрён в рабочие процессы компании.
