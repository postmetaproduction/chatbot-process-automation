# Логика работы Telegram-бота

## Как работает бот

1. Сотрудник отправляет сообщение в Telegram.
2. Модуль Telegram Bot (Watch Updates) получает сообщение.
3. Router в Make.com проверяет текст по заданным условиям.
4. Бот выбирает подходящую ветку и отправляет ответ пользователю.

## Сценарии обработки запросов

| Запрос | Условие | Результат |
|---|---|---|
| «Смета», «Скинь смету» | Содержит «смета» без учёта регистра | Ссылка на шаблоны смет |
| «КС-2», «Кс2» | Содержит предусмотренное ключевое слово | Ссылка на бланк КС-2 |
| «Отпуск» | Содержит «отпуск» | Инструкция и бланк заявления |
| Неизвестный запрос | Ни одно условие не выполнено | «Я не знаю такой команды» |

## Проверка логики

Изначально я использовала условие Equal to — точное совпадение текста. Из-за этого сообщения с разным регистром букв могли не распознаваться.

Изменила условие на Contains (case insensitive), чтобы бот мог находить ключевые слова внутри предложений независимо от регистра.

Также настроила ветку Fallback, чтобы пользователь получал ответ даже при неизвестном запросе.

## Ограничения

Бот работает по ключевым словам, поэтому не понимает все возможные формулировки. Передача обращения оператору в текущей версии не реализована.
